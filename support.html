Common questions

The scan finds nothing or the button is greyed out.
Join the room's Wi-Fi first. If the scan button still does nothing, turn on Local Network access: Settings → Privacy & Security → Local Network → SpyCam.

Does an empty scan mean there are no cameras?
No. A Wi-Fi scan only sees devices on the same network. Cameras on another network, on mobile data, or recording to a memory card won't appear. Always do the physical sweep too.

Why does it list some devices but hide others?
Many hotel networks isolate guests from each other, so you only see part of the network. The app tells you when it looks like this is happening.

What should I do if I find a camera?
Don't touch it. Take a photo, leave the room if you feel uncomfortable, and contact the host or hotel and the booking platform.
